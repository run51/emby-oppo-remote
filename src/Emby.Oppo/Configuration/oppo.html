Player

UDP-203 / UDP-205 or a compatible clone, on the same network as this server. Enable network standby on the player so that it can be turned on remotely.
Other OPPO playersOptional: more players in the "Play on" menu
Each player is offered in Emby's "Play on" menu under its own name and plays the films the same way as the main player (DLNA or the shares below). The TV, the amplifier, the webhook and the web remote stay with the main player.

Fallback if a film does not startOptional: shares the OPPO can mount
These shares are only used when the OPPO does not start a film over DLNA. A failed "Test" here does not prevent playback over DLNA (for example on Windows without SMB 1).
Each folder of your Emby libraries must match a share that the OPPO can mount. "Search" turns the OPPO on and lists the shares it sees; a match is suggested automatically. Check it with "Test".
When a Blu-ray is resumed, its main movie starts directly at the resume point instead of the disc's menu.
