Player

UDP-203 / UDP-205 or a compatible clone, on the same network as this server. Enable network standby on the player so that it can be turned on remotely.
The player accepts a single IP control connection (port 23). If another device controls it too (an Unfolded Circle remote, for example), run an oppo-multiplexer and enter its address, e.g. 192.168.1.20:23. Empty: the player itself.

Access to movies

Each folder of your Emby libraries must match a share that the OPPO can mount. "Search" turns the OPPO on and lists the shares it sees; a match is suggested automatically. Check it with "Test".

Home automation

Called with POST at the start ({"event":"detected","title":…}) and at the end ("stopped") of each movie, and by the remote control's Showtime / All off buttons ("seance_on" / "seance_off"). Home Assistant example: http://homeassistant:8123/api/webhook/my_id
If set, the Remote 2/3 turns the TV on over the network when a movie starts and with the Showtime button.
