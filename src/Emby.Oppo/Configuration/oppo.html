What's new

Player

UDP-203 / UDP-205 or a compatible clone, on the same network as this server. Enable network standby on the player so that it can be turned on remotely.
The player accepts a single IP control connection (port 23). If another device controls it too (an Unfolded Circle remote, for example), run an oppo-multiplexer and enter its address, e.g. 192.168.1.20:23. Empty: the player itself.
Adds a "Restart the OPPO" button to the remote: the same as unplugging the player, without touching the cable (stuck DLNA, IP control not answering…). Needs the jailbreak's jb_overlay with SSH.
The jb_overlay's ROOT_PWD, "oppo" by default.

Access to movies

Each folder of your Emby libraries must match a share that the OPPO can mount. "Search" turns the OPPO on and lists the shares it sees; a match is suggested automatically. Check it with "Test".
Requires the oppo-dv-mkv mod on the player with "DLNA Disc Images" on. The plugin serves the movie itself to the player: an ISO or a Blu-ray folder plays as a disc (menus and Dolby Vision included), an MKV, MP4 or M2TS file as a file. No share is mounted; the share above is only used if the movie does not start.
A free port on this server, reachable by the player. Restart Emby after changing it.

Home automation

Called with POST at the start ({"event":"detected","title":…}) and at the end ("stopped") of each movie, and by the remote control's Showtime / All off buttons ("seance_on" / "seance_off"). Home Assistant example: http://homeassistant:8123/api/webhook/my_id
If set, the Remote 2/3 turns the TV on over the network when a movie starts and with the Showtime button.
Used for the amplifier volume and mute buttons of the remote.
Create it in Home Assistant: your profile → Security → Long-lived access tokens.
Your own key (themoviedb.org → Settings → API): the remote then also shows the French trailers of each film.
What the amplifier decodes (Dolby TrueHD, DTS-HD MA…), shown while a film plays. Empty: sensor.<amplifier>_audio_format if it exists, else the amplifier's sound mode.
